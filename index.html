FAQ

အခမဲ့ Trial ကို ဘယ်လိုရမလဲ?

Bot ထဲက Free Trial ခလုတ်ကို နှိပ်လိုက်ရင် 1 GB Data နဲ့ 24 နာရီ သက်တမ်းရှိတဲ့ Key ချက်ချင်းရပါမယ်။ Telegram Account တစ်ခုလျှင် တစ်ကြိမ်သာ ရယူနိုင်ပါတယ်။

Data ကုန်သွားရင် ဘာဖြစ်မလဲ?

Data ဒါမှမဟုတ် သက်တမ်း ပြည့်သွားရင် Key က အလိုအလျောက် ရပ်သွားပါမယ်။ ဆက်သုံးချင်ရင် Bot ရဲ့ Renew Menu ကနေ ချက်ချင်း ဝယ်ယူနိုင်ပါတယ် — ရက်စောင့်စရာ မလိုပါဘူး။

သက်တမ်းမကုန်ခင် Renew လုပ်ရင် ကျန်ရက်တွေ ဆက်ပေါင်းပေးလား?

မပေါင်းပေးပါ။ Renew လုပ်ပြီးတာနဲ့ Key အသစ် ထုတ်ပေးပြီး၊ သက်တမ်းက ထုတ်ပေးသည့်နေ့မှ စ၍ ရက် ၃၀ ဖြစ်ပါတယ်။ ဒါကြောင့် Data ခန်းပြီးမှ Renew လုပ်တာ အသင့်တော်ဆုံးပါ။

Telegram မသုံးရင် ဘယ်လို ဝယ်ရမလဲ?

Telegram Account မရှိလည်း ရပါတယ်။ Facebook Page ကို သွားရောက် ဆက်သွယ်ပြီး ဝယ်ယူနိုင်ပါတယ်။ Admin က ငွေလက်ခံပြီး VPN Key ကို လက်ဖြင့် ထုတ်ပေးပါမယ်။ သက်တမ်းတိုးချိန်မှာလည်း Admin ကို ပြန်ဆက်သွယ်ရုံပါပဲ။
