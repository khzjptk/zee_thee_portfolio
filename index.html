FAQ

မေးလေ့ရှိသော မေးခွန်းများ

အခမဲ့ Trial ကို ဘယ်လိုရမလဲ?

Bot ထဲက Free Trial ခလုတ်ကို နှိပ်လိုက်ရင် 1 GB Data နဲ့ 24 နာရီ သက်တမ်းရှိတဲ့ Key ချက်ချင်းရပါမယ်။ Telegram Account တစ်ခုလျှင် တစ်ကြိမ်သာ ရယူနိုင်ပါတယ်။

Data ကုန်သွားရင် ဘာဖြစ်မလဲ?

Data ဒါမှမဟုတ် သက်တမ်း ပြည့်သွားရင် Key က အလိုအလျောက် ရပ်သွားပါမယ်။ ဆက်သုံးချင်ရင် Bot ရဲ့ Renew Menu ကနေ ချက်ချင်း ဝယ်ယူနိုင်ပါတယ် — ရက်စောင့်စရာ မလိုပါဘူး။

သက်တမ်းမကုန်ခင် Renew လုပ်ရင် ကျန်ရက်တွေ ဆက်ပေါင်းပေးလား?

မပေါင်းပေးပါ။ Renew လုပ်ပြီးတာနဲ့ Key အသစ် ထုတ်ပေးပြီး၊ သက်တမ်းက ထုတ်ပေးသည့်နေ့မှ စ၍ ရက် ၃၀ ဖြစ်ပါတယ်။ ဒါကြောင့် Data ခန်းပြီးမှ Renew လုပ်တာ အသင့်တော်ဆုံးပါ။

Device ဘယ်နှစ်လုံး သုံးလို့ရလဲ?

Zee Plus က Device ၂ လုံး တစ်ပြိုင်တည်း သုံးနိုင်ပါတယ်။ Zee Max ကတော့ Device အရေအတွက် အကန့်အသတ် မရှိပါဘူး။

၃ လ Plan က ဘယ်လို အလုပ်လုပ်လဲ?

တစ်ကြိမ်တည်း ငွေချေပြီး တစ်လစီ Cycle ၃ ခု ရပါမယ်။ ပထမ Cycle က ချက်ချင်းပွင့်ပြီး၊ ကျန်နှစ်ခုကို Renew Menu ကနေ မိမိကိုယ်တိုင် တောင်းခံရပါမယ်။ Admin အတည်ပြုပြီးမှ Key အသစ် ရောက်လာပါမယ် — ထပ်မံ ငွေပေးချေစရာ မလိုပါဘူး။

Key ကို သူငယ်ချင်းနဲ့ မျှဝေလို့ရလား?

လုံခြုံရေးအတွက် မမျှဝေဖို့ တိုက်တွန်းပါတယ်။ Key တစ်ခုရဲ့ Data ကို မျှဝေသုံးရင် မိမိရဲ့ Data ပိုမြန်ကုန်ပါလိမ့်မယ်။

Data နဲ့ သက်တမ်း ဘယ်လို စစ်ဆေးရမလဲ?

Bot ရဲ့ Package Status Menu မှာ လက်ရှိသုံးပြီးသား Data, ကျန်ရက်နဲ့ VPN Key ကို အချိန်မရွေး ကြည့်နိုင်ပါတယ်။ Data ၉၅% နဲ့ သက်တမ်းကုန်ခါနီး D-3 / D-1 မှာလည်း Bot က သတိပေးစာ ပို့ပေးပါမယ်။
